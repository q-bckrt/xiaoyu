02 Quad-Tier Typographic System
EASTERN CALLIGRAPHY & MODERN TYPE

Four typographic voices working in harmony. Each fulfills a distinct role, balancing calligraphic organic flow, literary reflection, modern geometric structure, and technical precision.

TIER 1 · IDENTITY MARK Zhi Mang Xing (志莽行书) · Calligraphic Signature
啸宇
The Mindful Craftsman

Application & Scope: Reserved strictly for the Chinese signature mark (啸宇). The dynamic ink brushstrokes evoke traditional Eastern calligraphy, cutting naturally across the modern digital grid.

TIER 2 · EDITORIAL SERIF Newsreader · Literary Warmth & Heritage
“Elegance is the quiet elimination of friction until only clarity remains.”

Application: Primary page headlines (H1/H2), philosophy callouts, manifesto quotes, and key statements.

TIER 3 · BODY / UI SANS Satoshi · Geometric Modernism
High performance stems from steady composure. When code, craft, and intent converge without friction, effort turns into effortless flow. Built with clean proportions and comfortable reading contrast.

Application: Body prose, navigation links, button text, form inputs, and card copy.

03 8px Baseline Grid & Spatial Cadence
GEOMETRIC DISCIPLINE & MA (留白)

All layout dimensions adhere strictly to an 8px base grid, subdivided into 4px micro-increments. Borders never exceed 1px solid. The canvas texture consists of an unshifting 16px Cartesian dot-matrix, balanced by deliberate negative space (留白 · Ma) that lets elements breathe with natural equilibrium.

04 Design Tokens Architecture
TOKENS.CSS IMPLEMENTATION

All values across the TAO ecosystem are strictly declared in tokens.css as CSS Custom Properties. The architecture separates Primitive Values (exact hex scales, fixed pixel steps) from Semantic Tokens (active canvas, ink priorities, elevation surfaces).
