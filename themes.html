04 Project Quickstart & Codex
IMPLEMENTATION & RULES

How to initiate any project using the Xiaoyu TAO design language. Three essential steps to preserve the spirit and integrity of the system.

STEP 1 Import tokens.css in your HTML <head>

Place this snippet inside your <head> element to load all fonts, tokens, and utility resets: 

<link rel="stylesheet" href="tokens.css">
STEP 2 Apply the 16px Cartesian Dot Matrix to your Body

Your body element will inherit the canvas color and subtle dot grid defined in tokens.css: 

body {
  background-color: var(--canvas-light);
  background-image: var(--grid-dot-pattern);
  background-size: var(--grid-dot-size) var(--grid-dot-size);
  color: var(--ink-primary);
  font-family: var(--font-sans);
}
STEP 3 Respect the 8px Spatial Baseline and 1px Hairlines

Never use rounded corners above 4px. Never exceed 1px solid borders. Ground spacing in --space-2 (8px), --space-4 (16px), or --space-6 (24px).
